# Running an event

A guide for the Paper Fox team. It grows as each part of the system is
built. Sign in at **Team sign in** (the link at the bottom of every page),
then use the menu at the top of the admin area.

## Making next year's (or next quarter's) event

The quickest way is to copy an event you've already set up:

1. Go to **Events** and open the event to copy, for example March 2027.
2. Choose **Copy this event**.
3. Check the name and start date. We suggest the same weekday a year on (so
   a Friday stays a Friday), and move the month and year in the name to
   match. Change them if you're making, say, June from March.
4. Choose **Copy event**.

The copy is a **draft**, so only the team can see it. Every date moves on by
the same number of days: the start and end, the balance due date and when
booking opens. Start times stay the same even when the clocks change, so a
9am start stays 9am.

The copy has the same options, prices and deposits, description, what's
included and hotel information. Two things to do before publishing:

- add the new event's **Facebook group** (each event has its own, so it's
  never copied);
- check the **hotel room** rates, which often change.

## Adding an event from scratch

Go to **Events → Add an event**. Picking the start date fills in the end date
(2 days later) and the balance due date (6 weeks before). You can change
either.

Leave **Add the usual two options** ticked to add:

- **Weekend (4pm start):** £195, with a £60 deposit;
- **Friday Kick Starter (9am start):** £245, with an £85 deposit.

## Options, prices and deposits

Open the event and choose **Change** under an option to change its price,
deposit or start time. Changing a price only affects new bookings.

- **Deposit:** what's paid to secure a place. The rest is due by the event's
  balance due date. Leave it empty if people pay in full.
- **On sale:** untick to stop people booking that option for a while.
- **Remove this option:** at the bottom of the option's page, if it's no
  longer offered at all.

## The balance due date

Each event has its own balance due date, 6 weeks before by default. Anyone
booking on or after that date pays in full. Change it under **Change
details**: for example, March 2027's is Tuesday 26 January 2027.

## Showing an event on the website

An event starts as a draft. At the bottom of the event's page, under **On the
website**:

- **Publish** shows it on the website. It needs at least one option on sale.
- **Mark as sold out** keeps it on the website, marked as sold out, with a
  note to email you to join the waiting list.
- **Reopen bookings** undoes sold out.
- **Unpublish** takes it off the website again.
- **Cancel this event** shows it as cancelled. This can't be undone.
- **Delete this draft** removes a draft you don't need.

Changes show on the website straight away.

## Venues

Go to **Venues** to change the Holiday Inn's details (address, phone, map
link, parking and access) or add another venue. These show on each event's
page.
